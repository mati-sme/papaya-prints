# Papaya Prints - store platform comparison (researched 2026-10-13)

## Shopify + Israeli payment provider (recommended starter)
- Shopify Basic: $29/mo billed yearly, $39/mo monthly. New stores: $1/mo for first 3 months. https://www.shopify.com/pricing
- Shopify Payments is NOT available in Israel, so a local gateway is needed; Shopify then adds a 2% fee per order on Basic (1% on Grow plan $79-105/mo).
- Storefront supports Hebrew/RTL (Dawn theme full RTL); admin stays in English. https://shopifyisrael.co.il/help/manual/start/getting-started/shopify-bahebrew
- Admin covers products, prices, inventory.

### Gateway: Grow (formerly Meshulam) - has Shopify app, supports cards, Bit, PayBox, Apple/Google Pay, installments, auto invoices/receipts. https://grow.business/shopify/
- Grow Light: 1% per transaction + ₪29/mo (annual ₪348), 20 transactions + 20 documents/mo included, ₪1 each beyond. https://grow.business/price-offer/
- Grow: 0.75% + ₪59/mo annual (₪708) or ₪69 monthly, 100 transactions/docs included. Prices excl. VAT.
- Payouts once a month on the 1st unless faster payout requested (fee).

### Gateway alt: PayPlus - Shopify integration, Bit/Apple Pay/Google Pay, branded checkout. Pricing not checked. https://www.payplus.co.il/en/shopify

Example: ₪100 sale on Shopify Basic + Grow Light = about ₪3 in % fees (2% Shopify + 1% Grow), plus fixed $29/mo + ₪29/mo.

## Konimbo (Israeli, fully managed)
- Official site now lists managed plans from ₪2,799/mo (Basic) and ₪3,399/mo (Full), excl. VAT, no setup fee. https://shop-konimbo.co.il/
- Older review: from ₪590/mo + setup, quote-based. https://arbiter.co.il/providers/konimbo
- Verdict: far too expensive for a starting side store.

## Cheapest fallback
- Keep current static site + Grow payment links/sales pages (no product admin/inventory). Fails the admin requirement.
