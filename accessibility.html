הצהרת נגישות

האתר פועל ליישום הנחיות הנגישות ככל שהדבר ניתן באתר סטטי זה, לרבות ניווט במקלדת, טקסט חלופי לתמונות, ניגודיות וכיבוד העדפת צמצום תנועה.

פניות בנושא נגישות ניתן לשלוח עם הזמנה או דרך פרטי הקשר שיופיעו בקופה.

Accessibility

This static site aims to support keyboard access, image alternatives, contrast, and reduced-motion preferences.

Accessibility requests can be sent with an order or through the contact details used at checkout.
